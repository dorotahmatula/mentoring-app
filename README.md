# Mentoring app

Aplikacja do prowadzenia procesów mentoringowych Doroty Matuły: sesje na żywo we dwie (szablon „Jak działamy i cele”, tablica, parking, głosowanie kropkami, „Co zabieram”), eksport do PNG i panel mentorki.

- Strona: https://mentoring.dorotamatula.pl (GitHub Pages)
- Dane i logowanie: Supabase (reguły dostępu pilnują, kto widzi którą sesję)
- Bez kroku budowania: czysty HTML, CSS i JavaScript

Puste pola w `config.js` uruchamiają tryb demo (dane tylko w przeglądarce).
